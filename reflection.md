For this project, I chose Option C, using a local Large Language Model through Ollama with the llama3.2:1b model. I chose this option because it allows the application to generate product descriptions locally without requiring a paid API key. The Flask web application accepts a product name and comma-separated keywords, sends the information to the local LLM, and displays the generated product description in the browser. One challenge during implementation was setting up Ollama on the computer and confirming that the local API and model were running correctly.

This application demonstrates how generative AI can support real-world retail and e-commerce by helping businesses create product descriptions more quickly and consistently. Future improvements could include tone selection, multiple description options, product category selection, and saving generated descriptions to a database. An important ethical consideration is that AI-generated content should be reviewed before publication because the model may add details or marketing claims that were not provided by the retailer. Human review can help ensure that product descriptions are accurate and do not mislead customers.
